# Administrator documentation

Guides for building, configuring and operating a VibeROM server.

This section is being written alongside the port. Until the server runs, the
authoritative record of administrative work is [TASKS.md](../../TASKS.md)
(T003, T020–T024, T063–T067, T074–T077).

Planned pages:

- `Building.md` — prerequisites, build, publish, run
- `Configuration.md` — every configuration key and default
- `DataLayout.md` — JSON areas, players, notes, gods, music, schemas, logs
- `ImportingLegacyData.md` — using `VibeROM.AreaImporter` once
- `Operations.md` — startup, shutdown, restart, copyover, backups
- `Administration.md` — accounts, bans, wizlock, immortals
- `OLC.md`, `BuildingAreas.md` — in-game editing and hand-editing JSON areas
- `Licensing.md` — Diku/Merc/ROM compliance checklist
